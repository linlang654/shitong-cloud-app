    1. 先测量一张标签纸，在上方选择相同尺寸；当前 Word 模板为 60 × 60 mm。

    部署说明

    1. 已建过基础表后，先执行 supabase-admin-upgrade.sql 增量脚本。
    2. 员工账号在 Authentication 创建，再到 profiles 表设置角色。
    3. 当前前端可部署到 GitHub Pages，摄像头扫码需要 HTTPS。
    4. 独立入口：courier.html 配送员端、factory.html 工厂端、track.html 学生查询。
